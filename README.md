# DesktopTodo - 极简桌面待办事项

DesktopTodo 是一个基于 Python 和 PySide6 开发的现代化桌面待办事项管理工具。它拥有简洁美观的界面，支持多种主题切换，旨在帮助你高效管理日常任务。

## ✨ 功能特性

- **📝 任务管理**：轻松添加、编辑、删除任务，一键标记完成状态。
- **📅 日历视图**：内置日历组件，直观查看和管理特定日期的待办事项。
- **🎨 多主题支持**：内置三种精美主题，满足不同审美需求：
  - ⚪ **极简白**：干净清爽，专注内容。
  - 🌑 **暗夜蓝**：深色模式，护眼舒适。
  - 🎨 **莫兰迪**：柔和配色，优雅大方。
- **⚡ 优先级标记**：通过不同颜色的侧边条区分任务优先级，重要事项一目了然。
- **🚀 开机自启**：支持设置随 Windows 系统启动，不错过任何计划。
- **📥 系统托盘**：支持最小化到系统托盘，后台静默运行，不占用任务栏空间。
- **💾 本地存储**：所有数据保存在本地 `todo_data.json` 文件中，安全可控。

## 🛠️ 安装与运行

### 环境要求

- Windows 操作系统
- Python 3.8+

### 1. 安装依赖

在项目根目录下打开终端，运行以下命令安装必要的库：

```bash
pip install PySide6
```

### 2. 运行程序

直接运行 `main.py` 启动应用：

```bash
python main.py
```

### 3. 打包为可执行文件 (可选)

如果你想将程序打包成 `.exe` 文件以便在没有 Python 环境的电脑上运行，可以使用 PyInstaller：

```bash
pip install pyinstaller
pyinstaller DesktopTodo.spec
```

打包完成后，可执行文件将位于 `dist/` 目录下。

## 📂 项目结构

- `main.py`: 程序主入口及核心逻辑。
- `todo_data.json`: 存储待办事项数据的 JSON 文件（自动生成）。
- `DesktopTodo.spec`: PyInstaller 打包配置文件。
- `icon.ico`: 应用程序图标。

## 📝 注意事项

- 程序首次运行时会自动创建 `todo_data.json` 文件。
- 开机自启功能会修改 Windows 注册表 `HKEY_CURRENT_USER` 下的相关键值。
